# Design benchmark

Integrated stage:
`python run.py run --stages design --profile full --data-work /path/to/study/core --output /path/to/new/run --workers 36`.

Full: 48,000 Gaussian and 4,800 count datasets.
Design-only quantities describe within-group information, estimability, residual
degrees of freedom and concentration across groups. Gaussian bias sensitivity
requires supplied mean/covariance assumptions.

The conditional screen is trained and evaluated on separate designs.
Unknown generating context produces abstention. Nominal BH (5%) and the
Monte Carlo screening ceiling (7.5%) are distinct. Global-null FDP intervals
are exact binomial; non-null mean FDP intervals use bounded t approximations.

Receipt verification controls resume. Incomplete tasks are recomputed.
Final summaries are generated by report.py.
Completed metrics can be summarized without refitting:
`python run.py report --design SOURCE --output NEW_DIR`.
